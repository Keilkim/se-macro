# SE Macro — CorelDRAW 매크로 모음

CorelDRAW에서 반복 작업을 줄여 주는 VBA 매크로 모음입니다.
**설치 파일 하나만 받아서 더블클릭**하면 끝납니다.

## 설치

1. [최신 설치 파일 받기](https://github.com/Keilkim/se-macro/releases/latest/download/SE_Macro_Setup.bat)
2. CorelDRAW를 완전히 종료
3. 받은 `SE_Macro_Setup.bat` 을 **더블클릭** (관리자 권한으로 실행하지 마세요)
4. 창이 뜨면 `[매크로 설치]` 탭 → `[설치 시작]`
5. CorelDRAW를 다시 켜고 `Alt+F8` → `SE메뉴.열기`

> 파일 하나 안에 매크로·설치 관리자·사용설명서·소스가 전부 들어 있습니다.
> 설치 후에도 이 파일을 보관해 두면 제거하거나 다시 설치할 때 그대로 쓸 수 있습니다.

## 업데이트

설치하고 나면 **CorelDRAW에서 `SE메뉴`를 열 때 새 버전이 있는지 알려 줍니다.**
알림 줄의 `[업데이트]` 버튼을 누르면 새 설치 파일을 받아 실행합니다.

직접 확인하려면 `SE메뉴` → 검색창에 `업데이트` → `새 버전 확인`.
사내망에서 막히면 `자동 확인 켜기/끄기`로 꺼 두면 됩니다.

## 들어 있는 기능

| 분류 | 기능 |
|---|---|
| 텍스트 | KoPub 돋움체 적용, 자간·공백·줄간격 세트, 폰트 크기 짝수 정수화, 줄 단위 분리, 호버 텍스트 편집 |
| 정렬 | 상하좌우 이격 정렬, 첫줄·끝줄 개체 정렬 |
| 페이지 | 넘버링, 마스터페이지 이동, 여러 페이지 붙여넣기, 캔버스 밖 삭제, 개체명 지우기, 전체 리샘플링 |
| 내보내기 | 페이지별 PDF 분할 저장, 페이지별 이미지 export(300DPI), HTML/SVG 임포트 |
| 도구 | 색상 팔레트, 로그 모니터 |

자세한 설명은 설치 파일을 실행한 뒤 관리자 창에서 사용설명서를 여세요.

## 요구 사항

- Windows
- CorelDRAW (VBA 매크로를 지원하는 버전)

## 문제가 생기면

- **"설치 파일을 찾을 수 없습니다"** — 파일이 덜 받아졌을 수 있습니다. 다시 받아 주세요.
- **백신이 막는 경우** — 이 파일은 서명되지 않은 배치 파일입니다. 사내 정책상 막힌다면 관리자에게 문의하세요.
- **설치했는데 목록에 안 보임** — CorelDRAW를 완전히 껐다 다시 켜야 반영됩니다.

## 이 저장소에 대해

배포물(설치 파일 + 버전 정보)만 공개합니다. 매크로 소스는 별도 비공개 저장소에서 관리합니다.
`version.json` 은 설치된 매크로가 새 버전을 확인할 때 읽는 파일입니다.
